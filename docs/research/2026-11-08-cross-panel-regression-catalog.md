# Cross-Panel Regression Tests to Port — Personal OMNIPANEL

**Review:** 2026-11-08. This is an **engineering test-design catalogue**, not a claim that OMNIPANEL already passes these cases. It records source-level behavior observed in upstream code/test files, the concrete failure that motivates the test, and the proposed OMNIPANEL test boundary. Tests are to be independently authored, not copied without a file-level license review. Source-linked [full 34-repository extraction](2026-11-08-personal-source-extraction.md) and [implementation plans](../plans/2026-11-08-personal-operator-extensions.md) govern priority.

## Translation principle

These tests address **observable OMNIPANEL outcomes**, not internal upstream call sequences. A corresponding source test file is proof of a repository's intended behavior only, not of external production correctness. All new Go packages/paths marked "proposed" must be added with a RED regression before changing behavior; existing module suites must remain green. For networking claims, run real signed native/root CI and independent public VPS/reference-client qualification [issue #14](https://github.com/AmirrezaFarnamTaheri/Omnipanel/issues/14). Personal default has **block-on-all-down**, **no IP-derived device identity**, **no trust-all TLS**, and **private administration**.
